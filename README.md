# 🏗️ Construction Site Tracker (OCIC – Mhamid)

A **Python + MySQL + HTML/JS** tool that automates construction progress tracking from Excel files (Gantt schedule and weekly progress reports), detects overdue tasks, and visualizes KPIs in an interactive dashboard.

## Features

- **Site initialization** – extracts lots, tasks, start dates, durations and contractors from an initial Excel schedule (`Table 1`, `Table 2`, `Table 7`).
- **Weekly import** – parses weekly Excel reports and updates task completion and field observations.
- **Delay detection** – compares planned end date (`start + duration`) with the report date and logs overdue tasks.
- **Exports** – an Excel summary workbook and a JSON feed for the dashboard.
- **Dashboard** – Chart.js charts (progress per lot, contractor workload) and a delay log.

## Installation

Requirements: Python 3.10+, MySQL/MariaDB (default port `3307`), a modern browser.

```bash
git clone https://github.com/imyasser/construction-site-tracker.git
cd construction-site-tracker
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
mysql -u root -p < database/schema.sql
```

## Configuration

Settings are read from environment variables (see `.env.example`); never commit real passwords.

```bash
export DB_PASSWORD="your_password"      # Windows PowerShell: $env:DB_PASSWORD="your_password"
export DB_PORT=3307
```

The Excel column names expected in the weekly reports are defined in `tracker/config.py` (`COLONNES`) and must match the file exactly, accents included.

## Usage

```bash
python main.py
```

1. **Import a weekly report** – Excel file name + report date (`YYYY-MM-DD`).
2. **Add a new site** – initialize from an initial Excel schedule.
3. **Export** – writes `output/export_suivi_mhamid.xlsx` and `dashboard/dashboard_data.json`.
4. **Quit**

## Viewing the dashboard

`dashboard/index.html` loads its data with `fetch()`, which browsers block on `file://`. Serve the folder:

```bash
cd dashboard
python -m http.server 8000
```

Open <http://localhost:8000/index.html>.
